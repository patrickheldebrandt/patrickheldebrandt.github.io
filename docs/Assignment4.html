Quanteda workflow > create a corpus, tokenize the text, remove unnecessary words, build a matrix, then analyze word patterns. Quanteda is useful because it converts large collections of text into structured data that can be compared.

[Quanteda Tutorial] (https://tutorials.quanteda.io)

The inaugural speeches can be compared by using word frequencies, common themes, and differences across presidents or parties. Wordfish is able to estimate the latent position of documents based on word usage. Documents that use similar vocabulary are placed closer together, while documents with different language patterns are placed further apart. We use Wordfish to help compare how the language of DOD reports change over time.

Question 4

**Wordfish** is a one dimensional scaling model that estimate the latent position of each document based on patterns in word usage. This makes it useful for identifying broad shifts in strategic language or emphasis across years and presidential administrations.

**Correspondence** analysis provides a multidimensional comparison of reports, as opposed to placing documents along a single scale, correspondence analysis can display documents and terms across multiple dimensions making it easier to identify clusters and relationship among reports.

\*\*Correspondence\*\* analysis provides a multidimensional comparison of reports, as opposed to placing documents along a single scale, correspondence analysis can display documents and terms across multiple dimensions making it easier to identify clusters and relationship among reports.
