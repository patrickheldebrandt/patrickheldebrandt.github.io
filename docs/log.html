Assignment 3

User

Conducting a linear regression returns this graph, provide alternative methods to improve the prediction capabilities. x is age, income, education and y is votes.

Assistant

Linear regression is not ideal because the dependent variable, votes, is binary. A better approach is logistic regression, which models the probability that vote = 1. Other methods include nonlinear terms, interaction terms, splines, decision trees, random forests, gradient boosting, and regularization.

User

Interpret a Logistic Regression, what does the output represent?

Assistant

Logistic regression models the probability that an outcome equals 1. The coefficients represent changes in log-odds, not direct changes in probability. Positive coefficients increase the likelihood of voting, while negative coefficients decrease it. Exponentiating coefficients gives odds ratios.

Finding Authors

User Prompt

The extraction is returning values like:

Introduced by Sen. GIANARIS

and sometimes:

Introduced by Sens. WEBB, COMRIE, RAMOS

I only want the actual author names.

I want the code to remove legislative titles like Sen. or Sens. but preserve the actual names. If there are multiple authors, I want all names kept rather than only the first one.

AI Response

The issue is that the scraper is correctly finding the author section, but the extracted string still includes legislative prefixes and surrounding text.

Suggested cleaning strategy:

  • remove prefixes such as:
    • Introduced by
    • Sen.
    • Sens.
    • Assembly Member
    • Representative
  • preserve multiple author names when listed
  • avoid deleting committee names
  • trim extra whitespace after cleaning

Example cleaning function:

clean_author <- function(author_text) {
  
  if (is.na(author_text) || author_text == "" || author_text == "N/A") {
    return("N/A")
  }
  
  author_clean <- author_text %>%
    str_remove(regex("(?i)^Introduced by\\s+")) %>%
    str_remove_all(regex("(?i)\\bSen\\.\\s*")) %>%
    str_remove_all(regex("(?i)\\bSens\\.\\s*")) %>%
    str_remove_all(regex("(?i)\\bAssembly Member\\s+")) %>%
    str_remove_all(regex("(?i)\\bRepresentative\\s+")) %>%
    str_squish()
  
  if (author_clean == "") {
    return("N/A")
  }
  
  return(author_clean)
}

clean_author <- function(author_text) {
  
  if (is.na(author_text) || author_text == "" || author_text == "N/A") {
    return("N/A")
  }

    str_remove(regex("(?i)^Introduced by\\s+")) %>%
    str_remove_all(regex("(?i)\\bSen\\.\\s*")) %>%
